# Rapid Cortisol

Статический сайт на HTML, CSS и JavaScript: https://idontknowwhatwritehere.github.io/cortisol-site/

## Обновление

Тексты сверены со сценарием и презентацией команды, научные утверждения проверены по первичным публикациям и рекомендациям. Ограничения и источники перечислены в FACT_CHECK.md. Контактное лицо — Виктория, учредитель ООО, согласно информации заказчика.

Добавлены светлая и тёмная темы, сохранение выбора в localStorage, плавные переходы и поддержка prefers-reduced-motion. Усилены начертания шрифтов, добавлены градиенты и текстуры фона. Фотография адаптера и интерфейс взяты из презентации, логотипы — из предоставленного изображения; видимые фрагменты выбираются CSS.

## Файлы

- index.html — содержание, семантические разделы и метаданные.
- style.css — обе темы, адаптивность и оформление.
- theme.js — выбор темы до отрисовки страницы.
- script.js — переключатель темы, меню и контактная форма.
- assets/research-slide.jpg и support-source.jpg — предоставленные изображения.
- FACT_CHECK.md — проверка содержания и ограничения.
- .nojekyll — отключение Jekyll на GitHub Pages.

## Запуск и публикация

Откройте index.html либо запустите `python3 -m http.server 8000` из этой папки и откройте http://localhost:8000. Сборка и зависимости не нужны.

GitHub Pages публикует корень ветки main. Все пути относительные и поддерживают размещение в подкаталоге репозитория. При обновлении CSS/JS изменяйте параметр версии в index.html, чтобы браузер не использовал устаревший кэш.

## Контакты

В script.js необходимо заполнить CONTACT_EMAIL реальным адресом Виктории. Пока он пуст, отправка отключена. После настройки форма передаёт письмо почтовому приложению через mailto; посетитель сам подтверждает отправку. Серверной отправки и хранения данных нет.

## Проверки

Проверены синтаксис JavaScript, ресурсы, якоря, уникальность id и дословная формулировка поддержки. Опубликованная версия проверена во встроенном браузере: светлая и тёмная темы, сохранение выбора после перезагрузки, мобильное меню и переход к разделу поддержки. На ширинах 320 и 390 px горизонтальной прокрутки нет, ошибок в консоли не обнаружено. Выполнен визуальный просмотр на настольной ширине. Отдельная полная проверка в Safari, Chrome и Firefox не проводилась.

## Что ещё требует данных команды

- Реальный контактный email и проверка отправки письма после его настройки.
- Подтверждённые характеристики, протоколы испытаний и объяснение расхождений калибровки: см. FACT_CHECK.md.
- Отдельные качественные оригиналы логотипов вместо фрагментов скриншота.
- Проверка требований отчётности по конкретному договору ФСИ. Договор не предоставлен, соответствие ему не подтверждено. Текст поддержки из ТЗ сохранён дословно; этого недостаточно для подтверждения полного соответствия.

Внешнее приложение-анализатор не изменялось.
