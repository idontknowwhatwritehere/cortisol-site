## Запуск и публикация

Откройте index.html либо запустите `python3 -m http.server 8000` из этой папки и откройте http://localhost:8000. Сборка и зависимости не нужны.

GitHub Pages публикует корень ветки main. Все пути относительные и поддерживают размещение в подкаталоге репозитория. При обновлении CSS/JS изменяйте параметр версии в index.html, чтобы браузер не использовал устаревший кэш.

## Контакты

CONTACT_EMAIL в script.js задан. Форма проверяет имя (от 2 символов), email и сообщение (10–1500 символов) и открывает почтовое приложение через mailto; письмо посетитель отправляет сам. Сервер данные не получает.

## Безопасность

CSP и Referrer Policy заданы через `<meta>` в index.html: скрипты и стили только со своего origin, `form-action`, `base-uri`, `object-src` запрещены. Заголовки HTTP (в т. ч. `frame-ancestors`, HSTS, `X-Content-Type-Options`) GitHub Pages настраивать не позволяет, поэтому защита от встраивания в iframe не обеспечивается. Inline-скрипты и inline-стили добавлять нельзя — CSP их заблокирует.

## Проверки

Проверены синтаксис JavaScript, ресурсы, якоря, уникальность id и дословная формулировка поддержки. Опубликованная версия проверена во встроенном браузере: светлая и тёмная темы, сохранение выбора после перезагрузки, мобильное меню и переход к разделу поддержки. На ширинах 320 и 390 px горизонтальной прокрутки нет, ошибок в консоли не обнаружено. Выполнен визуальный просмотр на настольной ширине. Отдельная полная проверка в Safari, Chrome и Firefox не проводилась.
