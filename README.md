# Rapid Cortisol

Сайт: https://vi-anhim.online/  
Приложение: https://app.vi-anhim.online/

Статический сайт на HTML, CSS и JavaScript. Сборка и зависимости не нужны.

## Запуск

```sh
python3 -m http.server 8000
```

Адрес: http://localhost:8000/. GitHub Pages публикует корень ветки `main`. Домен указан в `CNAME`.

## Файлы

- `index.html`: страницы и метаданные.
- `style.css`: оформление и адаптивность.
- `theme.js`: начальный выбор темы.
- `script.js`: меню, галерея, демонстрация и контактная форма.
- `assets/`: используемые изображения и иконки.
- `FACT_CHECK.md`: ограничения научных утверждений.
- `CONTENT_SOURCES.md`: источники материалов.

Контактная форма открывает почтовое приложение через `mailto:`. Отправку подтверждает посетитель. Серверной обработки формы нет.

CSP и Referrer Policy заданы в `index.html`. Перетаскивание изображений отключено; это не препятствует их скачиванию.
